# T101 技术规格

## 布局

```text
桌面                          手机
┌────────────────────┐        ┌──────────────┐
│ 标题与页签          │        │ 标题与页签    │
├───────┬────────────┤        ├──────────────┤
│ 搜索  │ 所选剧情    │        │ 搜索与楼层列表│
│ 楼层  │ 记忆预览    │        ├──────────────┤
│ 列表  │ 名称与备注  │        │ 所选剧情      │
├───────┴────────────┤        │ 名称与备注    │
│ 创建并进入分支      │        │ 记忆预览      │
└────────────────────┘        ├──────────────┤
                              │ 创建并进入分支│
                              └──────────────┘
```

界面通过 Shadow DOM 隔离。沿用宿主字体与主题变量，铜色表示选中和主要动作。移动端考虑安全区，按钮最小高度 44px。尊重减少动态效果设置。

## 模块

- `model.js` 负责角色或群组范围、楼层搜索、正文显示副本、分叉点指纹和柏宝书公开接口读取。搜索副本使用有字符上限的内存缓存，源消息改稿后失效。
- `service.js` 负责创建与导航。创建前校验聊天身份、所选正文与记忆叶子，记录操作，再调用原生分支入口。完成后核对目标聊天、消息数量、正文指纹与记忆。
- `store.js` 使用独立 IndexedDB，每条分支独立写入，事务完成后返回成功。创建记录在原生操作前落盘，中途失败保留待核对状态。
- `view.js` 负责搜索、楼层定位、预览、路线草稿、创建反馈和导航。显示动态内容统一使用文本节点。
- `index.js` 挂载魔杖菜单、消息按钮及 `/plot-branches` 命令，延迟导入宿主的原生分支模块。

## 创建与存储

分叉点采用包含目标楼的语义。UI 从 1 开始，传递给原生接口与柏宝书 API 时转成零基索引。

分支显示名称与备注保存在独立导航记录中。原生聊天文件名由宿主生成。记录仅保存身份、文件名、分叉点、名称、备注、时间、状态与检查结论。

单实例防重入与同源 Web Locks 配合使用。原生调用报错或返回空结果时显示待核对反馈，避免自动重试产生重复分支。保存记录失败发生在原生操作之后时，错误信息包含新聊天文件名。

所选消息之后的后续剧情不参与快照。记忆比较使用公开状态字段与绝对时间历史文本，忽略 API 修订号和聊天标识。原生生成的分支导航字段与动态隐藏标记不参与正文指纹。

## 边界

数据读取使用当前宿主上下文与柏宝书的只读公开 API。助手的创建入口调用 `branchChat()`，导航调用同角色的 `openCharacterChat()` 或同群组的 `openGroupChat()`。直接聊天写入方法和直接聊天写入请求不在助手实现中。

验证采用合成聊天与宿主替身，测试数据不来自真实角色、聊天或设置文件。
