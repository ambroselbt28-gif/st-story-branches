# 剧情分支助手

在 TauriTavern / SillyTavern 的历史消息里选择分叉点，预览当时的柏宝书记忆，给路线起名并创建聊天分支。支持手机和桌面。

## 安装

打开酒馆的 **扩展 → 安装扩展**，粘贴以下地址，分支留空。

```text
https://github.com/ambroselbt28-gif/st-story-branches
```

安装完成后重启酒馆。独立安装即可，入口名称为“剧情分支助手”。源码直接加载，无构建步骤。

## 使用

1. 打开要分支的聊天，点输入框旁的魔杖菜单 → **剧情分支助手**。
2. 输入剧情关键词、角色名或楼层号，选择要保留的最后一条消息。也可以在消息原生分支按钮旁点 **剧情分支**，直接定位到这一楼。
3. 查看分叉点的时间、地点、人物状态、物品和历史摘要，填写 **分支名称**，按需写路线备注。
4. 点 **创建并进入分支**。助手调用酒馆原生分支功能，创建截止到该楼的新聊天并切入。
5. 创建后会显示柏宝书状态与历史摘要的核对结果。在新聊天里输入新的选择继续剧情。
6. **我的分支** 中可进入已记录的分支，或点 **返回来源**。列表按当前角色或群组隔离。

还可以在酒馆输入 `/plot-branches` 打开助手，或用 `/plot-branches 100` 选择界面里的第 100 楼。本工具的楼层号从 **1** 开始。

**分支名称是助手内的显示名称。** 酒馆聊天列表中的文件名由原生分支功能生成，例如 `原聊天名 - Branch #1`。路线备注保存在助手中，续写时请在新聊天里输入你要采取的行动。

## 柏宝书记忆

读取柏宝书 API v1 的 `getSnapshot({floor, at:'after'})` 与 `getHistory({before:floor+1})`，预览所选楼层之后的状态与此前剧情。API 内部楼层编号从 0 开始，助手负责换算。

- **核对一致**表示新分支中公开接口返回的状态和历史摘要，与创建前在分叉点读取的结果一致。
- **存在缺口**表示部分应摘要的楼层缺少有效摘要，界面会列出楼层号。
- **结果不同**时保留已经创建的分支，并显示需要检查的提示。
- 柏宝书未安装、版本未提供公开接口或读取失败时，可以使用原生聊天分支，记忆核对显示为暂不可用。

核对范围是柏宝书公开的状态与历史摘要。向量召回、角色卡的其他变量系统和第三方插件的派生状态，需要在实际宿主中进一步验收。

## 保存与隐私

分支正文与原有记忆由酒馆原生分支功能保存。助手把名称、备注、来源、分叉楼层和核对结果保存在当前酒馆来源的独立 IndexedDB 数据库 `st-story-branches`。这些助手记录可随同一浏览器或 WebView 持续使用，跨设备及更换浏览器时需要分别建立记录。清理站点数据会清除这些导航记录。

预览用的正文与记忆仅保留在内存中。助手运行时使用宿主公开接口与本扩展同源资源。安装、检查更新和更新通过酒馆访问 GitHub。

## 兼容与验证

已核对 TauriTavern v2.4.0 与 main 的原生 `branchChat()` 接口，以及柏宝书 API v1。使用合成宿主完成 Node 逻辑验证、浏览器交互验证和 320 / 390 / 1024 像素宽度布局检查。实际手机 TT 与已安装柏宝书版本仍待验收。

```text
node dev/selftest.mjs
node dev/test-browser.mjs
```

浏览器验证使用本机已有的 Chrome / Edge。`node dev/preview.mjs` 启动合成预览，随后在浏览器打开 `http://127.0.0.1:8112`。全部样本是虚构剧情，原生创建接口使用合成替身。

在宿主中也可运行 `await stStoryBranchesSelfTest()`。该检查使用独立合成上下文与临时测试数据库。
